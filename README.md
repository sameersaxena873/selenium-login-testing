# Selenium Login Automation Testing

Automated test suite built with Python and Selenium WebDriver to validate login functionality on a web application.

## 🔧 Tech Stack
- Python
- Selenium WebDriver
- PyCharm / VS Code

## ✅ Test Cases
1. **Valid Login Test** — Verifies that a user with correct credentials is logged in successfully and redirected to a secure area.
2. **Invalid Login Test** — Verifies that an incorrect username/password combination shows the correct error message ("Your username is invalid!").
